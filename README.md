# Prompts

Internal engineering repository for managing prompts, standards, and related documentation.

## 🎯 Purpose

This repository is used to:
- Maintain reusable prompt assets
- Define prompt-related standards and best practices
- Centralize documentation for internal engineering use

## 📘 Documentation Guidelines

All documentation naming conventions, structure, and storage rules are defined in:

👉 **[PROJECT_DOCS_GUIDELINES.md](./PROJECT_DOCS_GUIDELINES.md)**

All contributors **must follow these guidelines**.

## 📦 Versioning Strategy

This repository follows **Semantic Versioning**:

```
MAJOR.MINOR.PATCH
```

- **MAJOR**: Breaking changes to prompts or standards
- **MINOR**: Backward-compatible additions or improvements
- **PATCH**: Fixes, clarifications, or documentation-only updates

## 📝 Change Log

All notable changes must be recorded in:
👉 **[CHANGELOG.md](./CHANGELOG.md)**

## 📂 Repository Structure

