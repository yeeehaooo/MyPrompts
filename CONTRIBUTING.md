# Contributing Guidelines

## 📌 Scope

This repository is an internal engineering asset.
All contributions must follow defined standards.

## ✅ Contribution Rules

- Follow documentation rules defined in `PROJECT_DOCS_GUIDELINES.md`
- Update `CHANGELOG.md` for any notable change
- Keep prompts and documentation versioned
- Avoid undocumented or experimental changes in main branches

## 🔁 Change Process

1. Create a feature or fix branch
2. Make changes with proper documentation
3. Update CHANGELOG.md
4. Submit for review

## ❌ Not Allowed

- Direct commits to protected branches
- Unversioned breaking changes
- Mixing draft and production-ready content
